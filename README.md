# Port & Vulnerability Scanner

![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)
![Nmap](https://img.shields.io/badge/Nmap-Required-orange.svg)

A comprehensive **Python-based vulnerability scanner** that identifies open ports, service versions, and associated **CVEs** using the **NIST NVD database**.  
Built for **security assessments** and **penetration testing**.

---

##  Features

*  **Port Scanning** — Uses Nmap for accurate service detection  
*  **Version Detection** — Identifies software versions on open ports  
* ️ **CVE Lookup** — Queries the NVD API for known vulnerabilities  
*  **Color-Coded Output** — Visual severity indicators (Critical / High / Medium / Low)  
*  **Multi-threaded** — Faster scans using concurrency  
*  **Modular Design** — Easy to extend and customize  
*  **Severity Filtering** — Filter results by vulnerability level  
*  **Risk Assessment** — Basic risk scoring for prioritization
